# CRUD Node.js - Advanced WEB

## 1. Hướng dẫn cài đặt và khởi chạy
1. Clone repository này về máy.
2. Chạy lệnh `npm install` để cài đặt các thư viện (express, mysql2, dotenv).
3. Tạo file `.env` ở thư mục gốc và cấu hình kết nối CSDL (DB_HOST, DB_PORT, DB_USER, DB_PASSWORD, DB_NAME).
4. Import file `STUDENTREG.sql` vào MySQL Workbench để tạo database.
5. Chạy lệnh `node index.js` để khởi động server tại cổng 3399.
